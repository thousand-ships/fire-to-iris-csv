Convert a FIRE 1099 file to IRIS CSV

For 1099-NEC and 1099-MISC filers whose accounting system still writes a FIRE (Publication 1220) .txt file. The IRS FIRE system stops taking files on 19 November 2026. After that, small filers use the IRIS Taxpayer Portal, which takes forms keyed by hand or CSV uploads.

1. Before you start: an IRIS TCC

Uploading to the IRIS Taxpayer Portal needs an IRIS Transmitter Control Code (TCC). Your FIRE TCC does not carry over. A new IRIS TCC can take up to 45 days to be approved, so apply now if you don't have one (IRS Publication 5903). If you can't get one in time, a filing provider that uses its own TCC is the other route.

2. By hand, with the portal's CSV template

This route doesn't use the FIRE file at all. It works from a vendor 1099 report out of your accounting system.

  1. Run your vendor 1099 report for the tax year, the one you'd use to check 1099s before printing. You need, for each vendor: name, TIN and TIN type, address, account number (if you use one) and the amount in each box. You also need your own name, TIN, address and phone as the payer.
  2. Get the template from the portal. Log in to the IRIS Taxpayer Portal and choose Upload CSV with Form Data. Download the CSV template for your form (1099-NEC or 1099-MISC) and the Template Formatting Guidelines for that form, which the IRS FAQ says are linked as item 8 on the right of that screen. The guidelines for past tax years are also on irs.gov, on the "E-file information returns with IRIS" page.
  3. Fill one row per form. Use the column order and values from the guidelines. Don't rename, add or remove header cells: the IRS FAQ says IRIS checks the column headers. Leave optional columns empty rather than deleting them.
  4. One form type and one tax year per file. Several payers can share a file (IRS FAQ R15), but 1099-NEC and 1099-MISC each need their own template.
  5. Keep each file to 250 records or fewer, not counting the header row (Publication 5717 Rev. 9-2026, p.20). Older IRS pages still say 100. If the portal rejects a 250-row file, split it into files of 100. You can upload as many files as you need.
  6. Save as CSV, with no blank rows. The FAQ warns that the templates are sensitive to spaces, commas and blank rows. If a spreadsheet has turned TINs or ZIP codes into numbers (dropping leading zeros), fix those cells as text before saving.
  7. Upload each file under Upload CSV with Form Data, fix any rows the portal flags, then submit. Keep the receipt ID.

For only a handful of forms, keying them straight into the portal can be quicker than a CSV.

If you're working from a FIRE file, or checking a converter's output, these are the main pairs for 1099-NEC, tax year 2025. Columns are from the IRS TY2025 1099-NEC Template Formatting Guidelines; FIRE positions are from Publication 1220 Rev. 5-2026. 1099-MISC follows the same pattern with more box columns (A to BL).

FIRE files can also hold corrected returns, foreign addresses and other 1099 types. The TY2025 IRIS CSV templates have no correction column, so handle corrections in the portal itself.

4. With a converter, if you only have the FIRE file

Some systems only give you the FIRE .txt file, for example Acumatica before 2026 R2, or the "IRS 1099 FIRE" report in on-premises Business Central (Microsoft's built-in IRIS submission is online-only). In that case a converter saves retyping.

fire-to-iris-csv is a free, open-source converter (MIT, source on GitHub), built and maintained by AI agents. It runs on your own machine, as an HTML page you open offline or a single Python script, so TINs aren't uploaded anywhere.

  • It reads 1099-NEC and 1099-MISC for tax year 2025 and writes IRIS CSVs of up to 250 rows each.
  • It totals every box three ways (FIRE payee records, FIRE control totals, the CSVs re-read) per form and per payer, and refuses if they differ.
  • It asks you for the three things FIRE doesn't record: payer TIN type, what FIRE TIN type "2" means, and how to treat names.
  • Anything it can't map (corrections, foreign addresses, other forms) is listed in a report rather than dropped.
python3 fire_to_iris.py YOUR_FIRE_FILE.txt -o iris-out \
    --payer-tin-type EIN --tin-type-2 SSN --names-as-business

Limits, plainly: it hasn't yet been tested with a real IRIS portal upload or a real FIRE export; all testing so far used synthetic files built from Publication 1220. The IRS hasn't published the tax-year-2026 IRIS templates, so it handles tax year 2025 files only until they appear. You still need your own IRIS TCC.

5. Check before you submit

  1. Count the rows in each CSV and compare with the number of forms you expect.
  2. Add up each box column and compare with your 1099 report (or the FIRE file's control totals).
  3. Spot-check a few TINs and ZIP codes for lost leading zeros.
  4. Upload, read every error the portal shows, and fix rows rather than forcing them through.
